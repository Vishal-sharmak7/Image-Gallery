# 🌅 Pic Horizon

## 📌 Overview
**Pic Horizon** is a sleek and interactive **image gallery web application** that lets users explore a variety of images across multiple categories, including **Emojis, Cars, and Places**. With an intuitive design and a built-in **light/dark theme toggle**, Pic Horizon ensures a seamless and visually appealing browsing experience.

## ✨ Features

### 🎨 Light/Dark Theme Toggle
Easily switch between **light and dark modes** with a simple click for a comfortable viewing experience, day or night. ☀️🌙

### 🖼️ Image Filtering by Category
Effortlessly browse images with a **category-based filter**:
- **All** – View the full collection.
- **Emoji** – Fun and expressive emoji images.
- **Cars** – Stunning car photography.
- **Places** – Beautiful locations from around the world.

### 📱 Responsive Design
Designed to look great on **all screen sizes**, whether you're on a desktop, tablet, or mobile device.

### ⚡ Interactive UI
Built with **HTML, CSS, and JavaScript**, the application dynamically updates the gallery based on user actions.

## 🛠️ Technologies Used

- **HTML** – Structures the web page elements.
- **CSS** – Styles the layout, including smooth theme transitions.
- **JavaScript** – Handles **theme toggling** and **dynamic image filtering**.

## 🚀 Usage Guide

### 🎭 Switching Between Light and Dark Themes
1. Click the **theme toggle button** (⚙️ icon) in the top corner.
2. Instantly switch between **light** and **dark modes** to suit your preference.

### 🏷️ Filtering Images by Category
1. Click on a category button (**All, Emoji, Cars, Places**).
2. Watch as the gallery updates to display only the selected category.
